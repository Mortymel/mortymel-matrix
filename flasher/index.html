PERFIL DISPONIBLE · ESP32-S3 DEVKITC-1 / 8 MB

Instalar por USB

Usa Chrome o Edge de escritorio, un cable USB de datos y una placa ESP32-S3 con flash de 8 MB y modo DIO. Se recomienda una primera instalación con el dispositivo vacío.

Este navegador no ofrece Web Serial. Abre la página en Chrome o Edge de escritorio mediante HTTPS.La página necesita HTTPS o localhost para acceder al puerto USB.

La primera instalación puede borrar los datos existentes. Guarda los ajustes y GIF antes de reinstalar. No selecciones otra variante de ESP32-S3 sin comprobar su flash y memoria.

Después del flasheo

  1. Abre Logs & Console en el instalador; reinicia el ESP32 si hace falta. A 115200 baudios verás el nombre y la contraseña del AP, y la clave web inicial.
  2. Conéctate a Mortymel-XXXXXX y abre http://192.168.4.1/. Usuario: admin.
  3. Configura Wi-Fi y cambia la contraseña web. En Sistema define GPIO E solo tras comprobar la conexión y los demás pines HUB75.
  4. Sube GIF en Biblioteca GIF y configura MQTT si usarás Home Assistant.

El firmware arranca con la salida HUB75 desactivada. Esta imagen no incluye un mapa universal de pines para cualquier placa.
