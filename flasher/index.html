01 / PRIMERA INSTALACIÓN

Flashea desde tu navegador

Instalación USB con detección automática para empezar. El dispositivo conserva la configuración entre reinicios; los cambios de contenido se hacen desde su web local.

DETECCIÓN AUTOMÁTICA

Conecta tu ESP32

El instalador lee la familia del chip y la capacidad de flash. Escoge el firmware compatible automáticamente; si no puede identificarlo, se detiene antes de escribir.

Listo para conectar.

Necesitas Chrome o Edge de escritorio, HTTPS y un cable USB de datos.

Antes de instalar

Una instalación nueva borra la flash completa: ajustes, contraseñas, GIF y otro firmware. El instalador pide confirmación después de detectar el dispositivo. Para actualizar una instalación existente usa el OTA desde su consola local.

RECORRIDO

  1. 01
    Conecta la placa

    Usa el puerto serie USB de tu placa, nativo o mediante un puente USB-UART si lo tiene. Selecciona el puerto correcto.

  2. 02
    Instala y lee el registro

    Al terminar, abre Registro serie aquí abajo a 115200 baudios y pulsa RESET. Anota el nombre y la clave del punto de acceso y la clave web.

  3. 03
    Abre la consola local

    Conéctate a Mortymel-XXXXXX, abre http://192.168.4.1/ e inicia sesión como admin. Configura Wi-Fi y cambia la clave web.

  4. 04
    Configura tu matriz

    Consulta el cableado HUB75, configura las 14 señales en Sistema y conecta E solo cuando el mapa coincida con tu panel.

02 / DIAGNÓSTICO

Registro serie

Abre el puerto después de instalar y pulsa RESET en la placa. Aquí aparecen la clave inicial del Wi-Fi y la contraseña de administración. Evita compartir capturas de estas claves.

04 / AYUDA
Si algo no aparece
No veo el puerto USB +
Prueba un cable de datos, desconecta otros monitores serie y selecciona el puerto correcto. Si la placa no entra en modo descarga, mantén BOOT pulsado, pulsa RESET y suelta BOOT; vuelve a conectar desde el instalador.
No aparecen las contraseñas +
Abre Registro serie, ajustado a 115200, y pulsa RESET. Si tu placa tiene USB nativo y USB-UART, prueba el otro conector. Si el dispositivo ya estaba configurado, usa las credenciales actuales; un borrado completo genera otras nuevas.
Home Assistant no detecta el dispositivo +
Activa la integración MQTT y un broker accesible desde la red del ESP32. Configura host, puerto y credenciales en Red y MQTT. Comprueba el indicador de conexión MQTT en la consola. Abrir guía MQTT.
La matriz queda en negro +
Es el estado previsto antes de definir GPIO E. Una matriz 64×64 1/32 scan también necesita que coincidan todas las demás señales, el tipo de barrido y la alimentación. Ver requisitos y límites y guía de conexiones físicas.
